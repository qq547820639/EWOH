## 2. 帧与消息

### 2.1 帧格式

全部多字节数值字段采用**小端**字节序。

| 顺序 | 字段 | 长度 | 说明 |
|---|---|---|---|
| 1 | 帧头 | 2B | 固定 0xAA55 |
| 2 | LEN | 1B | 载荷长度（PAYLOAD 字节数） |
| 3 | TYPE | 1B | 消息类型（见 2.2） |
| 4 | SEQ | 4B | uint32，单调递增，用于丢包检测与补传去重 |
| 5 | TS_MS | 8B | uint64，设备本地 epoch 毫秒 |
| 6 | PAYLOAD | LEN 字节 | 载荷 |
| 7 | CRC16 | 2B | CRC-16/CCITT-FALSE，覆盖 LEN..PAYLOAD |
| 8 | 帧尾 | 2B | 固定 0x0D0A |

### 2.2 消息类型（TYPE）

| TYPE | 名称 | 方向 | 周期/触发 | 载荷 |
|---|---|---|---|---|
| 0x02 | IDENT | 设备→平台 | 连接建立后首发；响应 IDENT_REQUEST | device_id 8B ASCII + fw 3B + hw 1B |
| 0x01 | HEARTBEAT | 设备→平台 | 1s 周期 | battery u8 + status u8 + fw 3B |
| 0x10 | TELEMETRY | 设备→平台 | 20Hz（50ms 周期） | 20B，见 2.3 |
| 0x11 | BACKFILL | 设备→平台 | 断线重连后补传缓存 | count u8 + count × 32B，见 2.4 |
| 0x20 | FAULT | 设备→平台 | 故障发生/恢复时 | code u8 + detail u8 |
| 0x81 | IDENT_REQUEST | 平台→设备 | 白名单命令，见 3.6 | — |
| 0x82 | TIME_SYNC | 平台→设备 | 白名单命令，见 3.6 | — |

### 2.3 TELEMETRY（0x10）载荷（20B，小端）

| 偏移 | 字段 | 类型 | 缩放 | 单位 |
|---|---|---|---|---|
| 0 | pitch | i16 | 0.1 | °（度） |
| 2 | roll | i16 | 0.1 | °（度） |
| 4 | ax | i16 | 1 | mg |
| 6 | ay | i16 | 1 | mg |
| 8 | az | i16 | 1 | mg |
| 10 | gx | i16 | 0.1 | dps（度/秒） |
| 12 | gy | i16 | 0.1 | dps |
| 14 | gz | i16 | 0.1 | dps |
| 16 | torque | i16 | 0.1 | Nm |
| 18 | assist | u8 | 1 | % |
| 19 | battery | u8 | 1 | % |

### 2.4 BACKFILL（0x11）载荷

断线缓存补传。载荷结构：count u8 + count ×（SEQ u32 + TS_MS u64 + 20B 遥测数据），每条 32B。遥测数据子结构与 2.3 相同。

### 2.5 FAULT（0x20）载荷与故障码

载荷：code u8 + detail u8。

| 故障码 | 名称 | 含义 | 设备端安全态 |
|---|---|---|---|
| 0x01 | IMU_FAULT | IMU 传感器异常，姿态/运动数据不可信 | 设备进入本地安全态，保持助力退出逻辑由设备控制器执行 |
| 0x02 | LOW_BATTERY | 电池电量低于安全阈值 | 设备进入本地安全态，保持助力退出逻辑由设备控制器执行 |
| 0x03 | OVERTEMP | 设备温度超过安全阈值 | 设备进入本地安全态，保持助力退出逻辑由设备控制器执行 |
| 0x04 | COMM_DEGRADED | 通信质量降级（丢包/延迟异常） | 设备进入本地安全态，保持助力退出逻辑由设备控制器执行 |

失联、低电、传感器异常等情形下，设备均进入本地安全态；助力退出逻辑始终由设备控制器本地执行，不依赖平台指令。

### 2.6 量程 / 单位 / 精度

| 物理量 | 量程 | 分辨率/精度 | 平台单位 |
|---|---|---|---|
| pitch / roll | ±180° | 0.1° | ° |
| 加速度 ax/ay/az | ±16000mg | 1mg | 平台换算为 m/s² |
| 角速度 gx/gy/gz | ±2000dps | 0.1dps | dps |
| 力矩 torque | ±100Nm | 0.1Nm | Nm |
| 助力 assist | 0–100% | 1% | 平台侧 assist_level 以 0–1 表示（= assist% ÷ 100） |
| 电量 battery | 0–100% | 1% | % |

## 3. 必须支持

### 3.1 设备身份与版本查询
连接建立后设备首先发送 IDENT（0x02），载荷含 device_id（8B ASCII）、fw（3B）、hw（1B）。平台可通过白名单命令 IDENT_REQUEST（0x81）主动查询。

### 3.2 心跳与在线状态
HEARTBEAT（0x01）周期 1s，载荷含 battery、status、fw。平台 **5s 未收到任何帧** 即判定设备离线并明确显示。

### 3.3 传感器健康、故障码与电量
故障经 FAULT（0x20）上报，故障码定义见 2.5；电量经心跳与遥测帧持续上报。

### 3.4 遥测数据及序号/时间戳
TELEMETRY（0x10）以 20Hz（50ms 周期）发送。TS_MS 为设备本地 epoch 毫秒；平台执行时钟对齐并记录 clock_offset_ms。SEQ 单调递增，用于丢包检测与补传去重。

### 3.5 断线重连、缓存与补传
设备重连后先发 IDENT，再经 BACKFILL（0x11）补传断线期间缓存数据（最多 300 条）。平台无需重启即可恢复接收与显示，补传数据按 SEQ 去重。

### 3.6 允许命令白名单
平台仅允许写入以下命令：

| 命令字 | 名称 | 确认要求 | 超时要求 |
|---|---|---|---|
| 0x81 | IDENT_REQUEST | 设备以 IDENT（0x02）帧应答确认 | 发出后等待应答超时由平台侧约定，超时重发或放弃 |
| 0x82 | TIME_SYNC | 设备执行后应答确认 | 发出后等待确认超时由平台侧约定，超时重发或放弃 |

白名单之外的任何写入命令平台一律不得实现、不得发送。

### 3.7 安全状态
失联、低电量、传感器异常、控制器异常时，设备进入本地安全态；保持助力退出逻辑由设备控制器执行（见 2.5）。

## 4. 禁止平台写入（安全红线）

**以下为安全红线，平台与大模型均不得实现任何指向以下能力的写入路径：**

- **关节实时控制目标**
- **关闭或放宽限扭/限速**
- **关闭急停与异常退出**
- **绕过本地安全校验的调试指令**

上述安全闭环能力全部归属设备控制器本地执行。平台（含适配层、推理引擎、本地助手与任何大模型组件）不得开发、暴露或转调任何实现上述写入的接口。

## 5. 标准消息示例

设备适配层输出的标准消息采用如下 JSON 结构：

```json
{
  "device_id": "NYA10001",
  "person_id": "P-0007",
  "timestamp": "2026-07-29T10:32:10.125+08:00",
  "sequence": 18201,
  "telemetry": {
    "pitch_deg": 32.1,
    "roll_deg": 2.4,
    "acceleration": [0.12, -0.05, 9.81],
    "angular_velocity": [1.2, 18.4, 0.6],
    "torque_nm": 12.5,
    "assist_level": 0.45,
    "battery_percent": 82
  },
  "quality": {
    "status": "good",
    "packet_loss": 0.002,
    "clock_offset_ms": 35
  },
  "source_type": "real"
}
```

字段说明：timestamp 为平台时钟对齐后的 ISO 8601 时间；sequence 来自帧 SEQ；acceleration 为三轴加速度（m/s²，由 mg 换算）；angular_velocity 为三轴角速度（dps）；quality.status 取值 good / degraded / invalid；source_type 取值 real / controlled_test / simulated。
