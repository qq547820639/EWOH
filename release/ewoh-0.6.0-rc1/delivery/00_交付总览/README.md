# EWOH 一次性交付包 V1.0

本包将《具身智能人员作业中枢完整实施手册》中的开发前任务、技术规范、项目管理、测试、安全和谈判演示产物一次性落地，并提供一个**完全本地、标准库运行、模拟数据明确标识**的 V0.5 原型。

## 快速使用

1. 先阅读 `01_开发基线/EWOH_开发基线冻结包_V1.0.docx`。
2. 打开 `EWOH_项目执行总控台_V1.0.xlsx`，分配真实负责人、日期和设备协议截止时间。
3. 进入 `06_Demo_Prototype`，双击 `start_demo.bat`（Windows）或执行 `bash start_demo.sh`（macOS/Linux）。
4. 浏览器访问 `http://127.0.0.1:8765`，按谈判演示手册完成六步演示。
5. 收到真实外骨骼协议后，按 `02_技术规范/device_protocol_spec.md` 替换模拟适配器。

## 交付状态

- 已完成：产品定义、PRD、架构、接口、数据模型、算法规格、模型治理、安全合规、测试验收、BOM、WBS、演示脚本、场景评估、模拟原型。
- 需要物理输入后完成：真实设备协议适配、真实数据采集、模型训练/评测、真实连续运行测试、捷顺正式接口联调、客户现场基线与验收。
- 严禁：将模拟结果描述为客户实测；让平台或大模型直接控制关节、限扭、限速、急停。
