# 04 设备配置清单

## 1. 数量估算规则
- **设备数 = 目标工序作业人数 × 35%，另加 10% 备机**（备机用于轮换、充电与故障替换）。
- 35% 为试点期覆盖比例，用于在保证数据代表性的同时控制投入；如需全员覆盖另行测算。
- 计算示例：作业人数 N 人 → 穿戴设备 ⌈N×35%⌉ 台，备机 ⌈N×35%×10%⌉ 台。
