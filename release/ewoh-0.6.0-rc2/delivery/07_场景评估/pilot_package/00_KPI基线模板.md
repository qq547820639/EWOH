# KPI 基线模板（标杆试点）

> 本模板用于试点前与客户共同确认四组 KPI 的定义、测量方式、基线与目标。
> **口径声明：任何人效提升结论仅限测试的具体工序、周期与人群，不得扩展为全厂承诺。**

## 使用说明
- 基线：试点开始前在目标工序实测或由客户既有记录确认；无法获得的标【待填：不可得】并说明替代口径。
- 目标：与客户书面确认，只针对本试点的工序、周期与人群。
- 统计口径：注明数据来源（平台遥测/事件记录/客户 MES-WMS 记录/问卷）、统计周期与样本范围。
