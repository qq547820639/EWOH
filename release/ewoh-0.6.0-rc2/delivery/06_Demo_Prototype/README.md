# EWOH V0.5 本地模拟原型

## 启动
- Windows：双击 `start_demo.bat`
- macOS/Linux：执行 `bash start_demo.sh`
- 浏览器：`http://127.0.0.1:8765`

仅依赖 Python 3 标准库，不需要联网或安装第三方包。

## 已实现
- 本地服务健康与断网说明
- 3台模拟外骨骼设备
- 站立/行走/弯腰/搬举/高负荷/异常动作的本地规则推理
- 负荷与疲劳趋势
- 风险事件与证据引用
- 可解释任务推荐
- 本地证据查询与越界拒答
- 场景评估与报告下载
- 一键重置

## 接入真机
将设备协议适配器输出转换为 `/api/telemetry` 使用的标准消息，或按 `02_技术规范/openapi.yaml` 替换当前模拟生成函数。真实设备接入后必须将 `source_type` 改为 `real`，并保留原始记录和协议版本。
