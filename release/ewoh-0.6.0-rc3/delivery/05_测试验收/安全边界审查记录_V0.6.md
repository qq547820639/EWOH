## 1. 审查目标

确认 EWOH 平台层是否不存在任何写入以下安全闭环参数的代码路径：

- 急停（emergency stop / estop）
- 限扭（joint torque limit）
- 关节实时控制（joint realtime control）
- 助力实时闭环（assist closed-loop）
- 限速放宽（speed limit relaxation）
- 异常退出保护（abnormal exit protection）
- 设备失联安全态修改（device-loss safety state modification）
- 绕过本地安全检查的调试指令（bypass local safety check）

预期结论：平台为只读接入（接收 + 解析 + 持久化 + 推理 + 展示），**不应**存在发送控制命令到设备的写路径。

## 5. 审查结论

### 5.1 总体结论

**平台不存在写入急停、限扭、关节实时控制、助力实时闭环、限速放宽、异常退出保护、设备失联安全态修改或绕过本地安全检查的代码路径。**

### 5.2 结论依据

1. **硬安全关键词零匹配**：`estop` / `emergency_stop` / `joint_torque` / `torque_limit` / `assist_level_set` / `closed_loop` / `realtime_control` / `joint_target` / `bypass_safety` / `disable_safety` / `firmware_overwrite` 在全代码库 0 匹配。
2. **「急停/限扭/关节」仅为安全声明与拒答规则**：所有中文安全语义匹配均为
   - `/api/status` 的只读声明字段 `safety_boundary`；
   - 模块 docstring / 前端 UI 警告文本；
   - 本地助手 `REFUSE_RULES` 拒答规则（遇到相关提问**拒绝回答**）；
   - selfcheck 中**验证拒答行为**的测试断言。
   以上均为**读**或**安全防护**逻辑，无任何**写**设备参数的可执行路径。
3. **POST 接口全部不触及设备控制**：6 个 POST 路由的写入对象分别为事件工作流状态、内存派工记录、演示数据重置（仅清非 real 数据），均非设备控制参数。
4. **adapter/protocol 层无写路径**：`edge/` 真实模块不存在；`stubs.AdapterManager` 仅有 start/stop，无 send_command；`stubs.Storage` 仅本地 SQLite 持久化；`DemoSimulator` 仅向平台写入模拟遥测，不向设备发命令。
5. **`assist_level` 字段为接收方向**：模拟遥测中的 `assist_level` 是设备→平台方向的**接收字段**，平台无对应的 `set` / `write` / `send` 调用。
6. **`firmware_version` 为只读元数据**：device 表存储 `firmware_version` 用于展示，无 `firmware_overwrite` 或远程刷写路径。
7. **架构声明一致**：`server.py:9` 模块 docstring 明确「本服务不提供任何写入急停、限扭、关节实时控制等安全闭环参数的接口」；`services.py:186-189` 明确「急停、限扭、关节实时控制等安全闭环参数由设备本地控制，平台与大模型无权写入或修改」「该能力在架构上不可绕过地保留在设备本地」。

### 5.3 安全边界确认

- 平台对设备为**只读接入**：仅接收 + 解析 + 持久化遥测、运行推理、生成风险事件、提供查询/推荐/评估，**无任何向设备发送控制命令的代码路径**。
- 急停、限扭、关节实时控制、助力实时闭环等安全闭环参数**由设备本地控制**，平台与大模型无权写入或修改，该边界在代码与声明层面均得到落实。
- 本地助手对「控制关节/急停/修改安全阈值」类提问**强制拒答**，且该拒答行为被 selfcheck 用例覆盖验证（selfcheck 24/24 通过）。
