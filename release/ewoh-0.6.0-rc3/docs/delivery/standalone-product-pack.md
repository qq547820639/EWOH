# EWOH Standalone Cloud Product Pack

Status: validated v1.2 (2026-08-04)

## Runtime

- NestJS standalone bootstrap (no Miaoda PlatformModule)
- JWT login/refresh/me + RBAC + bcrypt user table
- PostgreSQL 17 via Drizzle/postgres-js
- Redis via ioredis with in-memory fallback
- Global API rate limit guard
- File service with local disk and S3-compatible object storage drivers

## Work Orchestration Control Plane

- `GET/POST /api/work/*` file-backed execution graph, gates, evidence, agents,
  risks, resources, handoffs, and Final 6 asset catalog.
- Read model generated by `tools/work-indexer` from `.codex/artifacts`;
  repository files remain authoritative.
- Write APIs (resource locks, handoffs, gate decisions) append versioned
  records only when `EWOH_WORK_WRITABLE=true`.
- Offline-first GitHub Issue/PR sync plan via `tools/git-sync` and
  `GET /api/work/git-sync`; live creation is approval-gated.
- Factory replication acceptance TCK via `tools/factory-replication` with
  no-core-fork, replay, config satisfaction, and difference resolution gates.
- Factory site-readiness evaluator with device/ERP/network/training/retention
  evidence gates before real-factory replication drills.
- Work console site-readiness tab backed by `GET /api/work/site-readiness`
  over `catalog/factory-sites/*.json`.
- React console at `/work-orchestration` with DAG, gate, evidence, risk,
  resource, handoff, catalog, and Git sync views.

## Frontend
