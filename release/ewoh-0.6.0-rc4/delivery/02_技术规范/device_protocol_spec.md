# 设备协议规范模板

## 1. 基本信息
- 厂商/型号/硬件版本/固件版本
- 通信方式：BLE、串口、CAN、Wi-Fi、UDP、MQTT 等
- 负责人、协议版本和变更记录

## 2. 帧与消息
- 帧头、长度、消息类型、序号、时间戳、载荷、校验、帧尾
- 字节序、数据类型、量程、缩放、单位、异常值

## 3. 必须支持
1. 设备身份和版本查询
2. 心跳与在线状态
3. 传感器健康、故障码和电量
4. 遥测数据及序号/时间戳
5. 断线重连、缓存和补传
6. 允许命令的白名单、权限、确认、超时、幂等
7. 固件升级、签名校验和回滚
8. 安全状态：失联、低电量、传感器异常、控制器异常

## 4. 禁止平台写入
- 关节实时控制目标
- 关闭或放宽限扭/限速
- 关闭急停和异常退出
- 绕过本地安全校验的调试指令

## 5. 标准消息示例
```json
{
  "device_id": "EXO-001",
  "timestamp": "2026-07-29T10:32:10.125+08:00",
  "seq": 18201,
  "source_type": "real",
  "telemetry": {
    "pitch_deg": 32.1,
    "gyro_y_dps": 18.4,
    "assist_level": 0.35,
    "battery_pct": 82
  },
  "quality": {"status": "good", "packet_loss_pct": 0.2}
}
```
