## Completed

1. **ADR-060**：resource_reservation 决策投影语义（§29 十八问全作答）
   ——status=executed（执行步骤留痕非提议）/authority=rule_based
   （预占输入由 assignment 字段确定性推导）/风险映射复用 ADR-048
   决策 2 规则（§31 单一规则）/台账行唯一链接；追加 = 派工事务内
   写（同事务原子）；缺口不阻断派工主流程。
2. **projectResourceReservationDecision**：decisionId=
   `decision:<planId>:reservation:<assignmentId>:<reservationId>`
   确定性幂等（reservationId 单次生成 + double-dispatch CAS）；
   subject=`resource:<type>:<id>`；requiresApproval=false（审批事实
   在 kind #2）；selected.reason=reservationId:type:id:窗口（台账
   行唯一链接）；auditTrail actor=user:\<id\>|system:dispatch；
   validateDecision 门。
3. **dispatch-coordinator 接线**：预占循环收集真实 reserve() 返回
   结果 → `appendReservationDecisions` 与派工**同事务**读-追加-回写
   decision_records_json（无第二事实源；投影缺口/追加失败 log 显式
   绝不阻断派工主流程 §2）；getPlan 读回自动携带。
4. **测试**：decision-projection.spec +3 例（判定事实 / 缺省 actor
   + 幂等 / 缺口显式）+ dispatch-integration.spec 主链路断言补强
   （派工后方案决策台账含 kind #4 + validateDecision 门 + getPlan
   读回携带）；default jest 264 suites 1947→**1950** tests 全绿；
   双 tsc PASS。
5. **§36 评估**：canonical-decision-model 证据深化（保持 Implemented
   ——kind #4 生产调用链）；Decision Catalog kind 1/2/3/4 已接线。
