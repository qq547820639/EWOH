## Completed

1. **ADR-033（决策 1-4）**：边缘一等绑定 API；绑定事实经既有事件骨干
   上行（无第二上传路径）；云侧 ingest 幂等投影；目录 payload 增补。
2. **边缘绑定 API**：exo_binding 存储表（幂等建表）+ Storage
   start_binding/end_binding/get_binding/list_active_binding_for_exo/
   list_bindings + POST /api/exo/bind|unbind（规范身份 fail-closed、
   活跃绑定唯一冲突显式 409、状态机 active→ended + ended_by 必填、
   不存在 404、终态重复归还 409）。
3. **事件骨干上行**：绑定/解绑落本地账后发射 ExoSessionStarted/Ended
   Catalog 信封（契约校验 fail-closed）→ STREAM_EVENTS → EventUplink
   （at-least-once + 断点续传，NO-04b/04c 既有语义）。
4. **云侧 ingest 投影**：ExoSessionStarted→start（sessionId/exoId/
   personId/startedAt 透传）、ExoSessionEnded→end/abort（endedBy
   透传）；ExoSessionService 应用层幂等（同 sessionId start 回读、
   重复 end 原样返回）；投影失败显式留痕不阻断事件主事实（事件行仍
   落账，缺口可重放修复）。
5. **目录 payload 增补**：ExoSessionStarted/Ended +startedAt/endedBy/
   actualEndAt（additive）。
6. **测试**：edge test_exo_binding 6 例；ingest 投影 3 例；exo 幂等
   2 例。
7. **§36 升格**：worker-exoskeleton-loop → **Implemented**（矩阵
   **44/11/0/1** 计数自洽；project-state partial 移除）。
