## Completed

1. **ADR-035（决策 1-5）**：偏差图层 = 只读投影（服务端 deviationType
   权威分类 + 快照坐标事实，客户端绝不重判偏差）；纯 VM 装配；多通道
   视觉表达；executions 入调度聚合（单一消费路径）；图层开关 UI。
2. **纯 VM `executionDeviationMapVM`**：deviated（deviationType 非空，
   含终态历史可见）/ ontrack（无偏差 STARTED/PAUSED）双组；计划点=
   任务工位（回退 execution.stationId）、实际点=执行人当前位置（回退
   设备）；坐标缺失显式 null + missingCoordinates（禁止 0,0 伪坐标）；
   delta 按偏差类型取事实对（START_DELAY/END_DELAY/TRAVEL_DELAY，
   事实缺失不猜）+ 带符号 label（`+3.0min`/`-30s`）；未知
   deviationType 原样透出 + tone=neutral（§33 不静默）。13 例 node 测试。
3. **`ExecutionDeviationLayer`**（SchedulerLayers.tsx）：多通道视觉——
   空心方框=计划 / 实心圆点=实际 / 虚线=偏差（critical 红 / warning
   琥珀 / neutral 灰）/ 实线=进行中（绿）+ 偏差徽标 + delta + `<title>`
   全事实（task/status/偏差/原因/时长），非颜色唯一通道。
4. **executions 入 CommandMapAggregate**：30s 轮询、enabled=有选中方案、
   与列表面板（ExecutionDeviationList）同 React Query 缓存（无第二请求
   源）；`executionsError` 显式错误标记（图层开关旁「执行记录加载失败」
   提示，§33 不静默当作空）。
5. **图层开关生产 UI**：`CommandMapLayer` += execution-deviation；
   `toggleLayer` 纯函数（开→追加保持顺序 / 关→移除 / 幂等 / 不可变 /
   base 恒底层禁开关）；地图视口左上桌面端 chip 组（11 个可开关图层）。
6. **§36 评估**：logistics-task-loop 与 closed-loop-execution-feedback
   升 Implemented（矩阵 **45/10/0/1**）。无 DB/契约变更（纯 UI/VM
   投影层——契约面复用既有 SchedulingExecution / WorldStateSnapshot
   权威事实，不新建第二事实源）。
