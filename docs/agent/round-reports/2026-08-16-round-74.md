## Completed

1. **ADR-053（决策 1-3）**：rule-based-v1 语义（差异边界显式）；
   策略显式选择（无隐式回退）；MILP 随真实求解器库立项（§33）。
   §29 十八问全部作答。
2. **rule-based-scheduling-solver.ts**：确定性 L1 地板——
   - 任务序：前置 DAG 就绪集内按 (dueAtMs 升序, priority 降序,
     taskId 字典序) 稳定排序；
   - 候选序：共享 CandidateEngine.buildCandidatePool（§31 单一硬
     约束语义）的 eligible 候选中按 (startMs 最早, 资源 id 字典序)
     取首个——纯规则 first-eligible，**不做软成本 argmin**（与
     heuristic 8 权重优化的差异边界显式）；
   - 无可行候选 → `UNASSIGNED_RULE_BASED`（no_eligible_candidate /
     predecessor_unassigned）显式（§33 不伪造分配）；
   - 产出：status=shadow / solverStatus=`RULE_BASED` / solverVersion=
     `rule-based-v1`（Phase C 同纪律如实标记）；metrics 经统一评估器
     （P0-5）。
3. **策略路由**：solver.service——policy.solverVersion==='rule-based-v1'
   → ruleBasedSolver（无隐式自动回退）；SolverStatus +
   SolverActivationState additive +RULE_BASED。
4. **测试**：rule-based-scheduling-solver.spec 7 例（确定性重放
   deep-equal / 任务序 / priority tie-break / first-eligible +
   rejectedHard / DAG 前置 UNASSIGNED / lockedAssignments 透传 /
   routeCost 映射）；default jest 261 suites / **1912** tests（+7）、
   client 114/944 全绿；双 tsc PASS。
5. **§36 评估**：solver-pluggability 保持 Partial（阶梯三类 ✓ +
   差异边界 ✓ + 重放 ✓ + 可解释 ✓；MILP 环境阻塞 + CP-SAT 生产
   启用待部署环境）。
