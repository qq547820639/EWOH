## Completed

1. **ADR-045（决策 1-3）**：名称集抽象（契约形态优先 + 同源回退）；
   证书存在性与到期事实分工；快照索引与上下文同步收敛。
2. **5 个纯函数**（capability-projection.ts 增补）：capabilityNames /
   personSkillNames / deviceCapabilityNames / stationCapabilityNames /
   personCertificationExpiryMap——records（契约形态）优先；legacy
   直呼路径就地经同一投影函数推导（§31 单一语义，无第二事实源）。
3. **eligibility 收敛**：技能/设备能力/工位能力匹配改读契约形态；
   证书到期事实 records 优先 raw 回退；**证书存在性保持 raw**
   （certification 记录缺 issuer/expiry 被契约缺口丢弃是显式特性，
   改按记录存在性会改变既有语义——§30 禁止）。
4. **快照索引/上下文收敛**：求解器 personBySkill/deviceByCapability
   预筛索引改经契约形态名称集；candidate-engine + solver 的
   EligibilityContext 增补 stationCapabilityRecordsById（快照工位
   capabilityRecords 透传）。
5. **等价断言**：capability-projection.spec 14 例（+6：records 与
   raw 语义逐字一致 / 证书缺口到期未知不视为过期 / 过滤去重）；
   default jest 250 suites / **1854** tests、client 114/944 全绿；
   双 tsc PASS。
6. **§36 评估**：canonical-capability-model 证据深化——能力匹配
   端到端走契约形态（矩阵计数不变 49/6/0/1）。
