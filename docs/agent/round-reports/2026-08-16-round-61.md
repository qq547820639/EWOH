## Completed

1. **ADR-040（决策 1-4）**：边缘一等开灯 API；云侧 canonical 投影；
   通知共享助手；exo POST 分发缺口修复。
2. **边缘开灯 API**（`routes/andon.py` POST /api/andon/raise）：device:
   规范身份 + title 必填 + severity 封闭词表（critical/high/medium/low，
   缺省 high；未知词显式拒绝）+ slaSeconds 正数校验 fail-closed →
   AndonRaised Catalog 信封（source=edge:andon、subject=deviceId、
   payload 含 level/assignee/slaSeconds/raisedAt）经 STREAM_EVENTS →
   EventUplink 上行（at-least-once + 离线断点续传）；production 下
   需边缘认证（写操作，PUBLIC_POST_PATHS 仅 auth 端点）。
3. **云侧 canonical 投影**（ingest）：edge 源 AndonRaised →
   ewoh_event 行投影为与 oee.openAndon 同形状（eventCode=ANDON /
   severity=normalizeEventSeverity(payload.level) / andonId /
   slaMinutes / escalationLevel=0 / timeline[open] + envelope 证据）
   ——listAndons/transitionAndon/SLA 升级对边缘与云侧开灯统一消费；
   非 edge 源不投影（守卫边界 spec 锁定）。
4. **通知闭环共享助手**：`insertAndonNotifications`（app 恒建 + lark
   配置时建 + orgId 租户作用域）——oee 与 ingest 共用（§31）；
   ingest 侧通知失败显式留痕不阻断事件主事实。
5. **§30 边界修复**：registry ROUTE_TABLE POST 列表补 handle_exo
   （Round 54 绑定 API 从未经 HTTP 分发——直接 handler 测试掩盖）
   + 注册 handle_andon + dispatch 级回归锁定。
6. **测试**：edge test_andon_raise 9 例（unittest 954→**963** OK）；
   ingest spec +3 例（投影形状 / 通知闭环 / 非 edge 源守卫边界）；
   default jest 248 suites / **1807** tests 全绿；oee+notification
   30 例回归绿（共享助手重构）；双 tsc PASS。
7. **§36 评估**：andon-loop 边缘腿闭环，缺口收窄为邮件 SMTP 渠道
   （矩阵计数不变 47/8/0/1）。
