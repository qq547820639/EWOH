## Architecture Decisions

- 文本结果元数据在**生成端**（ArkService）统一装配，消费方（ai.service）只
  透传 kind/inputVersion——单一装配点，避免多路径各自拼装漂移。
- 失败路径同样留痕（ok=false + error），保证"LLM 不可用"本身可审计。
- 规则模板回退不伪造 reasoning（无 LLM 调用即无文本结果元数据）。
