# Round 98 — NO-13ab：控制面持久化修复（ADR-077）

日期：2026-08-16（EWOH 长周期 Agent）

## Current Objective

NO-13ab：控制面（ewoh_control_* 族）读面/写面复核——§2 监督式设备
指令域的持久化正确性、部署可用性与租户边界。

## Completed

1. **仓库事实发现三类真实缺陷**：
   - **schema 硬编码**：control.service 全部 raw SQL
     `insert into public.ewoh_control_*`——只在 standalone（public）
     成立，workspace 部署（__EWOH_SCHEMA__）中表不存在 → 控制面
     在真实部署潜伏不可用；
   - **无 drizzle 映射**：三表在 schema-manifest/001 为受管表
     （org_id uuid NOT NULL DEFAULT current GUC），schema.ts 完全
     未映射；
   - **org 归属缺口**：raw SQL 不含 org_id（依赖 DB GUC default）；
     读面 getRequest/findByIdempotencyKey 无 org 守卫——requestId
     跨租户读设备指令台账（§15/§16 私有操作数据）。
2. **ADR-077**（§29 十八问全作答）：三表映射 + drizzle 重写 +
   org 归属与守卫 + 契约 additive。
3. **schema.ts 三表映射**（列与 001 DDL 对齐；org_id uuid NOT
   NULL GUC default fail-closed；jsonb 承载 command_keys/
   response_json/result_json/payload）。
4. **control.service raw SQL → drizzle 全量重写**：insert/select/
   update + returning 类型安全链路，消除 public. 硬编码
   （workspace/standalone 双部署成立）。
5. **org 归属**：请求写侧 orgId = ctx.primaryOrgId（缺省省略列由
   DB GUC default 填充——GUC 空 → NOT NULL 显式失败，§33 不
   伪造）；命令/回执行归属 = 请求行 org（§3 单一事实源）。
6. **读面守卫**：getRequest/getStatus/findByIdempotencyKey 经
   assertTenantVisible（org 匹配或 NULL legacy 放行，跨租户
   404）；controller GET :id 注入 userContext；receipts 网关路径
   无 ctx → 请求行 org 派生（网关通道语义不变）。
7. **契约 additive**：ControlRequest += orgId?: string | null
   （读回归属事实）。
8. **测试**：control.service.spec 重写 14 例（orgId 注入/省略
   fail-closed/命令回执 org 同源/守卫 404/NULL legacy/审计面
   不变/§33 不吞异常）；legacy-org-id-mapping.spec +3 例（三表
   映射锁定，21 例）；共享助手 test/helpers/fake-control-db.ts
   （§31 单一假库）——control spec 与 scenario-packages SP-04
   共用（SP-04 迁移 drizzle 假库）。
9. **门禁全绿**：default jest 269 suites / **2041 tests**、
   client jest 120 suites/970 tests、双 tsc PASS、
   audit-domain-contracts 581/581、openapi 398/590 零漂移、
   repo-facts 39/39、reconcile 6/6 computed=74、feature-status
   32/32、env-inventory 124/125。
10. **§36 评估**：cross-tenant-isolation 证据深化（保持
    Implemented）——控制面持久化正确性 + 部署可用性 + 租户边界
    三修复；NO-13ab 收口。
