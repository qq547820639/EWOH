## Architecture Decisions

- 契约自检采用「落快照 + warn 留痕」而非中断构建：投影词表已由 ADR-007 收敛，
  自检是防御漂移的可观测证据（§33 不静默吞掉、§20 不因防御性校验破坏可用性）。
- entityId 与原 id 并存（ADR-008 Migration 的兼容策略），逐点收敛不一次性重写。
