## Completed

1. **ADR-056（决策 1-3）**：经验时长模型（非参数统计）；提供者替换
   （shadow-only 边界不变）；训练/激活闭环（唯一权威写路径）。
   §29 十八问全部作答。
2. **empirical-duration-model.ts（决策 1）**：train（真实时长样本 →
   median/p90 最近秩百分位/count/spread，确定性可重放）；置信度 =
   样本量 + 离散度真实推导（0.1..0.95 裁剪）；样本 < 5 →
   not_enough_data 显式 OOD（§33 绝不把 unknown 当 normal）。
3. **EmpiricalDurationPredictionProvider（决策 2）**：替换
   PREDICTION_PROVIDER——任务自带时长（任务级真实事实）→ 确定性
   路径；已训练 → median + ml 来源 + 真实置信度；未训练 → 显式回退
   确定性基线（source='deterministic'）；其余维度保持确定性基线。
   shadow-only 语义边界不变（预测只是优化器输入，绝不替代 hard
   constraints）。
4. **DurationModelTrainingService（决策 3）**：retrain（真实反馈
   actual_start/actual_end 双非空 → 训练 → ewoh_model_registry 落版
   （版本 = 既有最大数字版本 + 1；旧 active supersede）→ provider
   刷新；样本不足显式不落版）；hydrateFromRegistry 冷启动回填；
   POST /api/scheduler/predictions/task-duration/retrain 显式触发
   （OpenAPI 397/588 零漂移）。
5. **测试**：empirical-duration-prediction.spec 8 例 + duration-model-
   training.service.spec 5 例；default jest 261→263 suites
   1912→**1925** tests（+13）、client 117/962 全绿；双 tsc PASS。
6. **§36 评估**：intelligence-l7-learning 全绿升 **Implemented**
   （矩阵 53/2/0/1→**54/1/0/1**——L7 四腿闭环全部落地）。
