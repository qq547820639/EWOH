## Completed

1. **仓库事实发现真实泄漏风险**：retrain() 无 org 过滤混合全租户
   反馈训练全局模型（违反 §15/§16）；feedback 已有 org_id 列（基线
   写入 ctx 注入）；registry modelId 全局唯一无 org 列。
2. **ADR-070**：Model Training Policy v1（§29 十八问全作答）——
   租户作用域训练（跨租户聚合显式 OFF）+ modelId org 命名空间 +
   预测 org 键控 + retrain(orgId) 强制。
3. **modelId org 命名空间**：`task-duration-empirical:<orgId>` /
   `:<orgId>:<taskType>`（orgIdFromModelId 解析；旧全局模型显式
   弃用不回填）。
4. **provider org 键控**：orgModels + refreshForOrg +
   currentModelsForOrg；预测必须携带 task.orgId（缺 → 确定性基线
   显式 §33；他租户不共享）。
5. **training service org 强制**：retrain(orgId)（缺 → 400；
   feedback org_id 过滤）+ hydrateFromRegistry(orgId)（org 前缀
   过滤）+ cardJson 携带 orgId；controller 端点注入 userContext
   org。
6. **测试**：provider spec org 键控更新（10 例）+ training spec
   跨租户隔离 + 缺 org 400（9 例）；default jest 266 suites
   1976→**1978** tests 全绿；双 tsc PASS。
7. **§36 评估**：intelligence-l7-learning 证据深化（保持
   Implemented——§15/§16 机器强制收口；ADR-056/067 遗留边界关闭）。
