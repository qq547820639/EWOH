   HiGHS 爱丁堡大学高性能求解器 WASM 构建，MIT，无传递依赖，

   两次求解逐位一致）→ ADR-053 决策 3 的"MILP 环境阻塞"解除。
2. **ADR-058**：milp-v1 语义（§29 十八问全作答）——共享候选面 +
   联合行精确整数规划；heuristic=顺序贪心 vs MILP=联合精确最优
   （§9 唯一差异边界）；CP-SAT 生产启用仍为 OPEN-DECISIONS 唯一项。
3. **milp-scheduling-solver.ts**：CandidateEngine 候选面（§31）→
   二元变量 + 联合行（每任务至多一候选 / 人员·设备重叠互斥 /
   工位窗口容量 K 大 M 线性化 / DAG 闭包+前置无可行显式封锁 /
   DAG 时序冲突对）；目标 = 与 heuristic 同一 per-candidate 评分
   + M·未分配罚（M=1+⌈Σcost⌉，可证明"先最大化分配数、再最小化
   成本"字典序）；threads=1+random_seed=0 确定性；非 Optimal/
   加载失败显式抛出（§33）；violations 三分（no_eligible_candidate
   / predecessor_unassigned / no_feasible_assignment_milp）。
4. **接线**：solver.service 路由 policy.solverVersion='milp-v1'
   （显式选择、无隐式回退；solverActivation.state='MILP'）；
   SolverActivationState 联合 additive += 'MILP'。
5. **测试**：milp-scheduling-solver.spec 9 例（真实 HiGHS 求解：
   最优性 vs 穷举 / 容量冲突 / DAG 闭包·时序 / 工位容量互斥 /
   重放 deep-equal / 空任务 / 加载失败显式抛出）；default jest
   263→264 suites 1930→**1939** tests 全绿；双 tsc PASS；
   license:check PASS。
6. **治理**：feature-status += milpSolver + README 能力表行 +

   （已决 3→4）；矩阵 solver-pluggability 证据深化（保持 Partial：
   剩余 = CP-SAT 生产启用）。
