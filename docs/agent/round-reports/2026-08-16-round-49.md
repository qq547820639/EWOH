# Round 49 — NO-12e：边缘任务↔派工状态机同步（ADR-029，R-3 收口）

日期：2026-08-16（EWOH 长周期 Agent）

## Current Objective

NO-12e：closed-loop-execution-feedback——边缘 execute/update_task 不推进
对应任务/派工状态的分叉（R-3 遗留）修复，任务事实单一化（§3）。

## Completed

1. **ADR-029（决策 1-4）**：Task 是任务事实唯一权威、Assignment 是派工
   事实唯一权威，双方沿同一 TASK_TRANSITIONS 状态机双向收敛；execute()
   同步推进 Task；update_task() 同步推进其派工；同步失败显式留痕绝不
   静默。
2. **execute() 同步**：每个正式派工落账后，对应 Task 若存在且非
   dispatched：状态机校验（pending_dispatch→dispatched）+ 乐观锁更新；
   任务缺失（legacy 方案）→ 显式 warning 跳过；已一致 → 幂等跳过。
3. **update_task() 反向同步**：任务 API 推进 status 时沿最短合法链补全
   （dispatched→received→executing→completed 自动补全），其派工经共享
   转换器同链收敛（不回调任务防递归）。
4. **共享转换器重构**：set_assignment_status 的任务同步抽取为
   `_apply_assignment_transition` + `_sync_task_status` +
   `_sync_assignments_for_task`（§31 消除内联重复；force override 语义
   透传保留）。
5. **回归测试**：test_task_assignment_sync 7 例（execute 同步/缺失任务
   跳过/幂等/双向收敛/重复推进一致性/端到端三方一致）。
6. **§36 评估**：R-3 风险闭合（CR-EDGE-HYDRATE-COMPLETENESS）；
   logistics-task-loop 缺口收窄为地图端偏差图层（矩阵计数不变）。
