# Round 63 — NO-12s：审批前自动布局仿真预验证（ADR-042，调度决策自动消费仿真）

日期：2026-08-16（EWOH 长周期 Agent）

## Current Objective

NO-12s：调度决策自动消费仿真（L6 增强）——§13「高风险计划应尽可能
先在 Simulation 环境验证」在审批时刻没有机器支撑；为方案审批门
（PlanService.approvePlan，§2 人工决策门）提供确定性、可审计的
预验证事实。

## Completed

1. **ADR-042（决策 1-3）**：审批前自动运行 layout 仿真（advisory）；
   失败/跳过显式语义；确定性 + 缺事实显式。
2. **`pre-approval-simulation.ts` 纯函数**：方案分配（personId/
   stationId/plannedStart）+ 快照工位坐标 → 人员移动图（按人分组、
   plannedStart 排序、相邻异工位 = trips=1 边）；缺 plannedStart/
   personId/stationId 显式跳过计数；工位坐标 null 相关边显式跳过计数
   （不伪造坐标）；无移动链 → null（调用方显式 skip）。
3. **approvePlan 接线**：硬守卫（shadow guard/PLAN_STALE/安全关键
   锁定）通过后、状态落库前自动运行 `SimulationService.run(layout,
   runId=plan-approval:<planId> 确定性幂等, scenarioId=plan:<planId>)`；
   成功 → 审批审计 `after.preApprovalSimulation`（runId/status/
   totalTravelDistanceM/routesCount/engineVersion）；`getPlan` 附
   `preApprovalSimulation` 字段（台账回读）——求解器 walkingMeters
   的独立确定性交叉可审计（§18 解释来自真实评估器）。
4. **advisory 语义**：仿真失败/服务未装配/无移动链 → error /
   skippedReason（no_multi_station_route | simulation_service_
   unavailable）显式留痕，**绝不阻断审批**（§2/§13 人工门不变）。
5. **契约面 additive**：SchedulingPlanV2 += preApprovalSimulation
   可选字段；scheduler.module += SimulationModule（无循环依赖）。
6. **测试**：推导 7 例 + 服务接线 3 例；default jest **250 suites /
   1831 tests**、client jest 114 suites / 944 tests 全绿；双 tsc PASS。
7. **§36 评估**：L6 从「控制台人工触发」升级为「决策时刻自动消费」；
   intelligence-l6-simulation 证据深化（矩阵计数不变 48/7/0/1）。
