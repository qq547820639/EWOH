# Round 65 — NO-12u：Capability 契约消费方投影接线（ADR-044）

日期：2026-08-16（EWOH 长周期 Agent）

## Current Objective

NO-12u：ADR-043 决策 2 后续——把既有实体事实（人员技能/认证、设备
能力、工位能力）逐点投影为 Canonical CapabilityRecord，使能力事实
首次以契约形态进入生产调用链（§30 先契约后实现）。

## Completed

1. **ADR-044（决策 1-3）**：快照投影为唯一接线点；数据源缺口显式
   暴露；快照 additive 扩展。
2. **`capability-projection.ts` 纯模块**：projectPersonCapabilities
   （skills → skill 记录；certifications → certification 记录，
   expiresAt 取自 certificationExpiry 事实）/ projectDeviceCapabilities
   / projectStationCapabilities——每条记录经 validateCapability 契约
   门（fail-closed）。
3. **数据源缺口显式暴露（§33）**：认证缺到期事实 →
   `certification_missing_expiry:<name>`；人员数据源无 issuer → 契约
   门拒绝后改写为 `certification_missing_issuer:<name>`（绝不伪造
   issuer）；违规记录 → `projection_invalid:<id>:<errors>`——契约门
   恰好把数据源缺口显式暴露。
4. **buildSnapshot 唯一投影点**：WorldStateSnapshot person/device/
   station += `capabilityRecords`（契约合法记录）+ 顶层
   `capabilityProjectionIssues`（缺口显式计数）；类型 additive 扩展
   （shared/scheduler.ts），validateCloudWorldSnapshot 只校验
   entityVersions/身份引用，不受影响。
5. **测试**：capability-projection.spec 8 例；default jest 250 suites
   / **1848** tests、client jest 114 suites / 944 tests 全绿；双 tsc PASS。
6. **§36 评估**：canonical-capability-model 证据深化（矩阵计数不变
   49/6/0/1）；Record 化匹配收敛为后续轮次。
