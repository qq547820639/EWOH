## Architecture Decisions

- **ADR-006**：Canonical Industrial Identity（详见 ADR 文件）。关键取舍：拒绝 URI 形式
  （租户/工厂由事件信封承载）、拒绝开放注册表（类型完整性）、内部 ID 必须 EWOH 生成、
  第三方 ID 仅 alias、解析歧义 fail-closed、非破坏迁移（legacy 值保持可读，reconcile
  只增不改）。
- 门禁采用「独立仲裁」模式：解析规则在 JS 门禁内第三次实现，防止实现与测试向量互相腐化。
