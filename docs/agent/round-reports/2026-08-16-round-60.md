   resolved_at IS NULL CHECK + roles_json 数组 CHECK）；verify 自证

   ApprovalService 依赖；AgentModule 移除 ApprovalModule import

   审批超时台账化 expired / 待批清单台账读）46 例全绿；agent-policy-
   tck 台账 fake 化 46 例全绿；双 tsc PASS。
