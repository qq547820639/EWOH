# Round 96 — NO-13z：Legacy 受管表 org_id 映射漂移闭合（ADR-075）

日期：2026-08-16（EWOH 长周期 Agent）

## Current Objective

NO-13z：其余仓库事实缺口扫描（§3/§15 数据面漂移）——对照 001
ewoh_org_visible RLS 循环与 drizzle schema 映射，闭合组织归属
漂移。

## Completed

1. **仓库事实发现 P0 级潜伏漂移**：001 `ewoh_rls_normal` 循环对
   49 张受管表统一 `ENABLE RLS + ewoh_org_visible(org_id)`（严格
   语义：全局管理员或 org ∈ app.current_org_ids；GUC 未设置时
   coalesce 缺省 'true' 仅影响裸连接），而 schema.ts 有 **17 张
   表缺失 org_id 映射**——应用写入不携带 org_id → NULL 行在非
   admin 请求下被 **RLS WITH CHECK 拒绝 INSERT、USING 读回为空**
   （潜伏生产故障；与 CR-STANDALONE-CI-UNVERIFIED 同源——CI 从未
   在真实 PG 跑过这些路径）；standalone 引导路径由 drizzle 生成
   物理表无 org_id → RLS 循环 CREATE POLICY 引用不存在列。
   17 表：ai_suggestion/production_task/task_template/task_step/
   device_config/device_binding/organization/environment/
   model_registry/schedule_audit/event_chain/topology/telemetry/
   factory_template/factory_profile/asset_package/device。
2. **ADR-075**（§29 十八问全作答）：映射修复 + 写路径归属注入 +
   显式边界登记。
3. **schema.ts 全 17 表补 orgId 映射**（varchar 可空，与物理列
   对齐；uuid 值以字符串承载——ewoh_org_visible 内部 ::uuid
   兼容）+ 001 手写基线 CREATE TABLE 同补 org_id（fresh bootstrap
   路径与物理真相一致）。
4. **活跃写路径归属注入**：
   - schedule_audit：plan.service insertAudit(+orgId) 四站点
     （approve/reject/replan + constraint.deactivate 内联）；
     plan-application confirm/reject（gucContext）/override.apply
     （ctx）；gamification 四站点（allocate/orchestrate/dispatch/
     brain_apply——brain_apply 补 actor 透传，controller @Req）；
   - telemetry/device（ingest）：批量与单帧路径行级注入
     ctx.primaryOrgId（无租户上下文 → NULL 显式 legacy 不伪造）；
   - model_registry（persistModel）：orgId = orgIdFromModelId
     （R-91 modelId org 命名空间唯一事实源，§3 不新建第二来源）；
   - simulator telemetry/device：orgId = EWOH_SIMULATOR_ORG_ID
     （与 withSimulatorOrgContext GUC 同源，§13 模拟数据显式标记）。
5. **显式边界登记（NO-13aa）**：sensor-ingest ingestEnvironment
   （frame 无租户字段）、organization.createOrganization（org 行
   归属=自身 id 需回读改造）、dashboard.createDevice（无 actor
   签名）保持 NULL 并登记下一波改造，不在本轮伪造 org。
6. **测试**：legacy-org-id-mapping.spec 18 例（17 表映射锁定 +
   数量不缩水）；gamification spec audit 行 orgId 断言×2；
   training spec registry 行 orgId 断言；training harness matcher
   元数据过滤器修复（新增 org_id 列元数据串误入 org 值过滤——
   排除含 '_' 标识符）。
7. **门禁全绿**：default jest 268→269 suites / 2018→**2036 tests**、
   client jest 120 suites/970 tests、双 tsc PASS、
   audit-domain-contracts 581/581、openapi 398/590 零漂移、
   repo-facts 39/39、reconcile 6/6 computed=74、feature-status
   32/32、env-inventory 124/125。
8. **§36 评估**：cross-tenant-isolation 证据深化（保持
   Implemented）——数据面 schema↔物理漂移闭合；NO-13z 收口。
