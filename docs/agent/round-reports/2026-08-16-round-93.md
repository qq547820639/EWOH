# Round 93 — NO-13w：Scheduler 读面组织隔离第二波（ADR-072）

日期：2026-08-16（EWOH 长周期 Agent）

## Current Objective

NO-13w：其余仓库事实缺口扫描（§15 调度域读面）——ADR-071 收口
方案行之后，复核 run/audit/constraint/decision-history 四读面的
租户边界并闭合。

## Completed

1. **仓库事实发现四类残留缺口**：
   - getRun(runId) 零应用层守卫（RLS 单层）；
   - ewoh_schedule_audit **无 org_id 列、无 RLS**——audit 行只挂
     planId，无 planId 时全表返回、有 planId 时可读任意租户方案
     审计（真实跨租户审计读泄漏）；
   - listPlanConstraints(planId) 读面无 org 条件（防御纵深缺失）；
   - decision-history 方案来源查询读**全部租户**方案行，仅靠记录级
     tenantId 过滤，注释仍声称"plan 表无 org_id 列"（与 R-92
     相同的过时注释类问题）。
2. **ADR-072**（§29 十八问全作答）：守卫泛化 + getRun 守卫 +
   getAudit 父方案归属子查询过滤（不为 audit 新建 org 列，§3 单一
   事实源）+ constraint 读面 org 条件 + decision-history 方案来源
   SQL org 条件（记录级过滤留第二层）+ controller 三路由
   userContext；无 DB/契约/OpenAPI 变更。
3. **守卫泛化（§31）**：plan-tenant-guard.ts 增补
   `assertTenantVisible(orgId, actor, subjectLabel?)` 为唯一实现；
   `assertPlanTenantVisible` 保留同签名别名（R-92 调用点不变）。
4. **getRun(runId, actor?)**：行读取后守卫（NULL 存量放行、跨租户
   404 反枚举，与 RLS 语义等价）。
5. **getAudit(planId?, actor?)**：actor 提供时审计行按父方案可见性
   过滤——`planId IN (SELECT planId FROM ewoh_schedule_plan WHERE
   org_id IS NULL OR org_id = :org)`（归属由父方案事实推导）。
6. **listPlanConstraints(planId, actor?)**：约束行 org 条件（org
   匹配或 NULL 存量）。
7. **decision-history**：方案来源查询追加 SQL org 条件 + 修正文件头
   与内联过时注释（记录级 tenantId 过滤保留为第二层）。
8. **facade/controller**：GET runs/:runId、GET audit、GET
   plans/:planId/constraints 注入 request.userContext。
9. **测试**：plan-org-isolation.spec 16→25 例（+通用守卫 1 +
   getRun 3 + getAudit 3 + listPlanConstraints 2）；decision-
   history spec +1 例（SQL org 节点断言 + 双层过滤行为）；facade
   oracle actor 参数更新。
10. **门禁全绿**：default jest 267 suites 1999→**2009 tests**、
    client jest 120 suites/970 tests、双 tsc PASS、
    audit-domain-contracts 581/581、openapi 398/590 零漂移、
    repo-facts 39/39、reconcile 6/6 computed=74、feature-status
    32/32、env-inventory 124/125。
11. **§36 评估**：cross-tenant-isolation 证据深化（保持
    Implemented）——调度域读面应用层 org 闭合 + RLS 双层一致；
    NO-13w 收口。

  显式声明）；若 audit 直查面扩大，优先补 org_id + RLS（候选
  standalone_056）。
- NULL=全局/存量行语义与 standalone_025 对齐（不放宽不收紧）。
- CR-STANDALONE-032-054-CI-UNVERIFIED 维持（无本地 PG，迁移链
  未经真实 PostgreSQL 实测）。
