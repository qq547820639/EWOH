## Architecture Decisions

- 投影词表归一采用「显式映射 + 未知→UNKNOWN + warn 留痕」而非静默猜测：
  符合 ADR-007「存量非法值显式 UNKNOWN 化，不静默改写」。
- 空间类型在 ingest 边界 fail-closed 拒绝 + 读边界防御校验（双保险），
  避免脏类型进入 ewoh_spatial_entity。
- 测试修复方向：把测试期望升级到契约词表（而非让契约迁就旧测试），
  符合 §33「不让测试适应错误实现」的反向纪律。
