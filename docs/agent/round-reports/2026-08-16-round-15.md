     severity 走 Risk 契约、subject 走 Identity 契约。

   重实现 validate/transition 语义 + schema 形状 + 双运行时注册表逐位比对），
   **182→216 项，216/216 PASS**。
5. **Golden Scenario 第 8 场景** `workorder_loop`（9 case：合法工单×2 / 全路径 /
   跳步拒绝 / in_progress 不可取消 / 取消路径 / completed 缺时间戳 /
   cancelled 缺原因 / origin 缺失），Python/TS 双执行器共享定义全通过。
