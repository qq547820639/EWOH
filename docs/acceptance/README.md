# 验收文档

本文件为 EWOH 受控试点系统的验收文档骨架，包含 P0 验收指标、测试层级、
故障注入清单、验收证据包字段与 Go/No-Go 门禁清单。
详细用例见 `05_测试验收/`。

## P0 验收指标（15 项）

| 序号 | 指标                                   | 目标值           | 验证方式           |
|------|----------------------------------------|------------------|--------------------|
| 1    | 平台冷启动可用时间                     | ≤ 60 s           | 计时               |
| 2    | API P95 响应延迟（读类）               | ≤ 300 ms         | 压测               |
| 3    | 遥测采集端到端延迟                     | ≤ 500 ms         | 时戳比对           |
| 4    | 事件检出召回率                         | ≥ 95%            | 标注集回归         |
| 5    | 事件误报率                             | ≤ 5%             | 标注集回归         |
| 6    | 设备失联安全态触发                     | ≤ EWOH_OFFLINE_AFTER_SEC | 故障注入   |
| 7    | 真机适配层接入成功率                   | 100%（试点设备） | 联调               |
| 8    | 鉴权与角色越权拦截率                   | 100%             | 越权用例           |
| 9    | 审计日志完整性（写操作覆盖率）         | 100%             | 审计比对           |
| 10   | 数据导出权限控制                       | 仅授权角色可用   | 角色矩阵测试       |
| 11   | 备份恢复成功率                         | 100%             | 恢复演练           |
| 12   | 高频遥测保留窗口                       | 7-30 天可配      | 配置与过期校验     |
| 13   | 来源标识准确性（real/controlled_test/simulated） | 100%    | 串源检测           |
| 14   | 急停等设备控制不被平台下发             | 0 次违规         | grep 守护+人工审查 |
| 15   | 离线运行能力（无公网依赖）             | 全功能可用       | 断网演练           |

## 测试层级（13 层）

1. 单元测试（unittest）
2. 模块集成测试
3. 适配层契约测试
4. API 契约测试（OpenAPI 校验）
5. 鉴权与权限测试（RBAC）
6. 审计完整性测试
7. 数据保留与过期测试
8. 故障注入测试
9. 性能与压测
10. 端到端场景测试
11. 离线/断网测试
12. 备份恢复演练
13. 现场试点验收测试

## 故障注入清单（16 类）

1. 设备心跳中断（失联安全态）
2. 适配层端口串源
3. 鉴权令牌过期/伪造
4. 角色越权访问
5. DB 连接中断
6. DB 慢查询/超时
7. Redis 不可用
8. 磁盘写满
9. 系统时钟漂移
10. 网络分区（内网隔离）
11. 推理管线崩溃
12. 推理延迟突增
13. 高频遥测洪流
14. 导出并发爆发
15. 审计日志写入失败
16. 配置错误（非法环境变量）

## 验收证据包字段

每项验收需提交证据包，至少包含：

- 用例编号与版本
- 测试层级
- 执行时间与执行人
- 环境与配置快照（脱敏）
- 输入数据来源标识（real/controlled_test/simulated）
- 原始日志/截图/导出文件
- 测试结果（通过/失败/阻塞）
- 偏差与免责说明
- 复核人与复核结论

## Go/No-Go 门禁清单（15 条）

试点放行须同时满足以下全部条件（全部为 Go 方可放行）：

1. P0 验收指标 15 项全部达成
2. 13 层测试全部通过
3. 16 类故障注入全部完成且平台未下发任何设备实时控制指令
4. 真机适配层联调通过
5. 鉴权与角色矩阵测试通过
6. 审计日志完整性验证通过
7. 数据保留与导出权限合规
8. 备份恢复演练成功
9. 离线运行能力验证通过
10. 安全边界人工审查通过（无平台下发急停/限扭/关节控制等）
11. 隐私原则落实（无未授权敏感数据采集）
12. 四区部署网络隔离验证通过
13. 监控告警接入并完成一次告警闭环
14. 现场人员授权与同意记录齐备
15. 应急停止流程演练通过
