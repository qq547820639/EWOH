EWOH 设计系统界面原型 v1

EWOH 界面设计方案

本原型使用 client/src/tokens.css 与 tailwind-theme.css 中的生产真实令牌值构建。 切换右上角主题可验证：语义令牌在浅色 / 暗色 / 高对比三套主题下均保持 AA 级以上对比度， 而页面内 368 处 Tailwind 硬编码色对这三套主题全部无响应。

1 · 状态色板

六个业务状态，每个状态四个维度：主色（填充/图标）、软底（背景）、边框、前景（文字）。 面板标注的对比度为「软底 + 前景文字」实测值，全部高于 WCAG AA 的 4.5:1。

2 · 排版与触控

中文优先字体栈（PingFang SC / 微软雅黑），正文 14px / 行高 1.6。 所有数字使用等宽数字（tabular-nums）保证表格纵向对齐。工业手套场景触控目标不小于 44px。

3 · 指标卡：替换 JSON dump

方案卡片当前直接渲染 JSON.stringify(row.metrics)，调度员需要阅读原始结构。 指标卡将同组数据转为「大数字 + 单位 + 语义色 + 阈值提示」，原始结构折叠进「查看原始指标」供排查使用。
