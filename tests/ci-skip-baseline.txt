# 格式：`文件 :: 原因 :: 允许次数`（原因取 pytest `-rs` 汇总行的原文，去掉行尾句号）
#
# 为什么要有这个文件：`pytest` 与 `unittest` 对**被跳过**的用例退出码仍是 0。
# 本仓库 CP-SAT 求解/预约用例带 `skipUnless(_ORT_TOOLS_AVAILABLE)` 守卫，而 CI 的 Python
# job 只装 ruff/bandit/pytest、不装 ortools → 求解路径在 CI 里静默全跳仍然绿。
# 门禁 `scripts/assert-test-skips.py` 因此要求：每一次跳过都必须在这里被显式登记，且数量不得增加。
#
# 纪律（与 db/migration-verify-baseline.txt 同一条）：
#   · 基线只允许缩小——可选依赖装好后这里会打印 FIXED，请删掉对应行；
#   · 新增跳过或某类跳过数量变多 → 门禁非零退出；
#   · 登记 = 承认「这条路径当前没有被验证」，不是让它永久合法。
