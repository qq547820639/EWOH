# Inventory Reports

Inventory reports are evidence of the current baseline. Each report must state
whether it was verified against the live worktree (`confirmed_current`) or
derived from prior state (`memory_derived` / `stale_or_unverified`).

Expected files:

- `docs-gap-report.md`
- `python-backend.md`
- `frontend-nestjs.md`
- `environment.md`
