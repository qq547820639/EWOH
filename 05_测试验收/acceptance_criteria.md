# P0 验收标准

| 类别 | 指标 | 门槛 |
|---|---|---|
| 设备 | 上线可见 | 10秒内 |
| 设备 | 连续采集 | 真机目标2小时；模拟8小时 |
| 设备 | 断线恢复 | 60秒内恢复状态 |
| 平台 | 状态刷新 | 2秒内 |
| 推理 | P95延迟 | 500ms内（演示目标） |
| 事件 | 触发到页面 | 2秒内 |
| 事件 | 证据 | 前后30秒或配置窗口 |
| 推荐 | 返回候选 | 5秒内且含分项理由 |
| 离线 | 六步演示 | 无公网完成 |
| 恢复 | 一键重置 | 2分钟内 |
| 真实性 | 来源标识 | 页面/导出全覆盖 |

所有指标在真实设备未接入时只能验证模拟工程能力，不得替代真机验收。
