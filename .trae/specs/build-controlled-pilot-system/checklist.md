## 阶段 3：推理、规则和模型
- [ ] 处理链落地（遥测→质量检查→时间窗→特征→动作识别→负荷→风险规则→事件去重→证据绑定→通知）
- [ ] 动作分类支持 stand/walk/bend/lift/carry/unknown

- [ ] 每条规则配置 rule_id/rule_version/启用/阈值/持续/恢复/冷却/等级/适用设备固件/证据字段/审批人/生效时间

- [ ] 事件防抖具备持续时间门槛/滞回区间/冷却/相同事件合并/状态恢复自动收口/重复告警抑制/设备重连事件续接/规则版本记录
- [ ] 12—20 名健康成人受控采集，每人每动作 10—20 次或连续 3—5 分钟
- [ ] 人员告知授权/匿名 ID/设备固件记录/传感器校准/动作脚本/重量台面次数持续时间/视频仅标注参考/双人标注+第三人仲裁

- [ ] 训练/验证/测试集按人员划分，同一人不跨集合
- [ ] 受控测试集 Macro-F1≥0.85、核心动作召回≥0.90、unknown 机制测试全通过
- [ ] 人员独立测试（测试人员不在训练集）
- [ ] 模型推理 P95≤500ms，输出携带版本/置信度/数据质量

- [ ] 模型上线流程落地（数据集冻结→训练→独立评测→模型卡→安全评审→候选模型→影子运行→受控验证→人工批准→小范围启用→持续监控）
- [ ] 禁止模型自动在线学习直接覆盖生产模型
