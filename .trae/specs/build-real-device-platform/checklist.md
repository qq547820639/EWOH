# Checklist

## 范围冻结
- [ ] 《真实设备协议确认书》齐备（帧格式/时间戳/字段单位量程/心跳重连缓存/故障码/版本获取/命令白名单/禁止写入清单/失联安全态）
- [ ] V0.1 动作集合（3–5 类）与第一版风险事件（2–3 类）已冻结并落入数据/事件字典

## 真机链路（G2）
- [ ] 私有协议仅经适配层接入，业务系统不直接解析私有协议
- [ ] 标准数据模型字段齐全（device_id/person_id/timestamp/sequence/telemetry/quality/source_type）
- [ ] 单台真机连续运行 ≥2 小时且有完整运行日志
- [ ] 核心字段完整率达到约定值，时间戳与平台统一对齐
- [ ] 通信中断后平台明确显示离线；恢复后无需人工重启平台
- [ ] 可按时间段导出原始数据片段并回放真实数据
- [ ] 页面与导出明确显示 `REAL DEVICE` 来源
- [ ] 平台无任何写入急停/限扭/关节闭环参数的路径
- [ ] G2 评审记录归档；G2 通过前未启动模型训练与新增前端功能

## 数据与算法（G3）
- [ ] 6–10 名授权人员完成受控采集，每次采集记录元数据全字段
- [ ] 训练/验证/测试集按人员划分，同一人不跨集合
- [ ] 动作识别人员独立测试 Macro-F1 达到冻结指标（内部目标 ≥0.85）
- [ ] 全部算法支持 `unknown` 并输出原因
- [ ] 推理结果携带置信度/数据质量/模型版本/推理时间/时间窗/关键特征/是否规则/是否进入事件判断
- [ ] 边缘主机单次推理 P95 <300ms，页面端到端更新 <2s
- [ ] 风险事件字段齐全且可追溯到原始数据，证据窗为事件前后各 30 秒
- [ ] 模型可一键回滚；模型不可用时自动退回规则模式
- [ ] 评测报告与模型卡归档；无模型直接控制关节的路径

## 平台与演示
- [ ] 九个页面全部显示来源/更新时间/数据质量/设备与模型版本/异常状态/原始证据入口
- [ ] 真人动作可使页面数据真实变化；实时与回放明确区分
- [ ] 重启后数据恢复；断公网后系统持续运行
- [ ] 任务推荐含分项理由与硬约束拦截，且必须人工确认
- [ ] 助手仅答白名单问题并引用真实记录证据；7 类拒绝全部生效
- [ ] 无公网完成 15 分钟六步演示并可连续重复；真机/模拟可切换；一键重置 ≤2 分钟

- [ ] 每个候选客户输出一页纸评估
