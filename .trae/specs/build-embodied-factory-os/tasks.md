# Tasks

> 与已完成的 `build-controlled-pilot-system`（V0.6 受控试点基线）衔接：本 spec 在其工程基线、真实设备只读接入、身份权限、审计、四区部署、P0 验收基础上做空间孪生、感知融合、世界模型、调度仿真、指挥地图扩展，不重复其已闭环内容（工程基线/CI/分支策略/8 类角色/审计/备份恢复演练/13 层测试/P0 指标）。
> 外部前置（非代码，由项目执行总控台跟踪，不展开为开发任务）：试点车间与 3—5 关键工位、20—50 试点人员授权、外骨骼型号与协议、CAD/BIM/平面图/设备布局/摄像头安装/UWB 基站/消防安全区域/工位编号/物流路线资料、摄像头视频协议与访问权限、MES/WMS/AGV/PLC 接口、三维扫描与建模资源、边缘服务器/GPU/UWB/网络/UPS 硬件、人因与安全合规支持。
> 首期范围严控：1 工厂 / 1 产线或车间 / 3—5 关键工位 / 20—50 人 / 10—30 套外骨骼 / 1 种主要工序 / 1 类核心调度问题。
> 版本路线：V0.7 空间底座与地图 → V0.8 多传感器融合 → V0.9 世界模型和回放 → V1.0 受控调度建议 → V1.1 场景仿真 → V2.0 多车间和跨工厂协同。
